# 说明

肺癌与癌旁正常组织的差异表达分析（GSE10072）。下面所有数字来自实际运行结果，可用 results/summary.txt 复核。

## 一、要解决的问题

肺癌组织和癌旁正常组织之间，哪些基因的表达差异最大？这个差异是否稳定到值得继续做富集分析和生存分析？

选 GSE10072 的理由：样本量适中（107 例）、分组清楚（肿瘤 58 / 正常 49）、平台是 Affymetrix HG-U133A（GPL96），注释齐全，适合作为第一条完整流程的练手数据。

## 二、怎么做的

1. 从 GEO 下载 series matrix 文件（13 MB），解析表达矩阵与样本信息；
2. 按 !Sample_title 和 !Sample_source_name_ch1 的关键词分成肿瘤组与正常组；
3. 剔除缺失超过 20% 的探针；确认数据已是 log2 尺度，未再转换；
4. 每个探针对两组做 Welch t 检验，再用 Benjamini-Hochberg 方法校正得到 FDR；
5. 用 GPL96 注释表把探针映射到基因符号，同一基因有多个探针时，取**平均表达最高**的那个探针作为代表（n_probes 列记录原有探针数）；
6. 以 FDR < 0.05、|log2FC| ≥ 1 为界挑出差异基因。

一条命令复现：

    python src/run_all.py --input data/GSE10072_series_matrix.txt.gz --annot data/GPL96_annot.tsv

## 三、结果

- 样本：肿瘤 58 例，正常 49 例
- 探针 22283 个 → 合并后 14426 个基因
- 显著差异：599 个基因，其中上调 206、下调 393
- 上调最强：SPP1（+4.4）、COL11A1（+3.1）、MMP1（+2.9）、SPINK1（+2.8）、GREM1（+2.5）、COL10A1（+2.5）
- 下调最强：AGER（-4.4）、FABP4（-3.8）、FAM107A（-3.4）、SFTPC（-3.0）
- 其他可验证的标志：TOP2A（+2.5）、COL1A1（+2.3）、CDH5（-2.6）、PECAM1（-1.8）、VWF（-2.3）、TEK（-2.5）

**怎么读这组数字**：上调的一侧集中在增殖（TOP2A）、细胞外基质重塑（COL11A1、COL1A1、COL10A1）和炎症/肿瘤微环境（SPP1、MMP1、GREM1）；下调的一侧集中在正常肺泡上皮（AGER、SFTPC、FABP4）和血管内皮（CDH5、PECAM1、VWF、TEK）。换句话说，肿瘤组织里"正常肺的结构"被整体压低，"增殖与基质"被整体抬高——这和肺癌的病理常识一致，说明流程没有跑偏。

## 四、已经处理的三个问题

1. **同一基因多个探针**：已合并。取平均表达最高的探针，COL1A1 由 4 个探针收敛为 1 个（+2.33），SFTPC 由 5 个收敛为 1 个（-2.99）。合并前后的差异在 summary.txt 里有记录（22283 探针 → 14426 基因）。
2. **注释缺失**：注释表里查不到的探针，直接用探针号当基因名，不再被合并成空值。
3. **对数尺度判断**：脚本会先看数值范围，确认数据已是 log2，避免对已取对数的数据再取一次。

## 五、还没做、也做不了的

- **批次校正**：GSE10072 是单一研究、单一平台，没有批次可校正；真正需要校正的是多数据集合并，那是下一步。
- **外部验证**：还没有用 TCGA-LUAD 独立验证。这是最实在的下一步：同一条流程换一个队列，看 599 个基因里有多少能复现。
- **因果**：差异表达只说明两组之间相关，不说明因果。
- **富集**：还没做 GO/KEGG，但从基因列表看，预期会落在细胞外基质与血管生成通路上——这正是下一步要验证的假设。
